# daisyUI frontend

Use Tailwind CSS 4 and daisyUI 5 in the Vue frontend, with the built-in light and dark themes following the operating system. Restyle every frontend view and shared game panel for mobile and desktop without changing game behavior. Use component and utility classes directly, retaining app-specific CSS only when necessary. Keep native controls, labels, keyboard access, and readable ticket states.

See the two implementation issues and the styling decision in `../../docs/adr/0003-tailwind-daisyui-for-styling.md`.

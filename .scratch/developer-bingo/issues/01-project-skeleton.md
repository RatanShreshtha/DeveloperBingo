# 01: Project skeleton

**What to build:** A FastAPI backend and a Vue app that run together. The backend connects to Postgres, and the frontend shows the backend's health on a page. Generated TypeScript types come from the backend's OpenAPI schema.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] The backend and frontend start with one command each
- [x] A health endpoint reports the database connection status
- [x] The Vue page shows that health status
- [x] TypeScript types are generated from the OpenAPI schema
- [x] A test runs in CI or locally for the backend and the frontend

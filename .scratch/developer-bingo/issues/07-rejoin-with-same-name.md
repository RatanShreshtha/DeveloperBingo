# 07: Rejoin with the same name

**What to build:** A player who drops and rejoins with the same name gets the same ticket and the same ticks back.

**Blocked by:** 06 (Tick drawn topics)

**Status:** ready-for-agent

- [ ] Rejoining with the same name before the game ends restores the ticket
- [ ] Rejoining restores the player's ticks
- [ ] A rejoin with a name that belongs to no one in the game is treated as a new join, not a restore
- [ ] A rejoin is not possible after the game ends
